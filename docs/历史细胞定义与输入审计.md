# 历史细胞定义与输入审计 / Historical input audit

这是已完成审计的发布摘要。完整本机证据、供者表、原脚本和路径保留本地。本次没有重跑QC、细胞选择、TF发现或JUND科研分析。

**120细胞为冻结多基因规则得到的成纤维细胞炎症程序富集集合，不是正式确认的亚群。460基因模型不能支持“炎症性成纤维细胞特异性JUND抗炎机制”。**

## 来源与细胞状态

来源 [Lin, Weimin，Zenodo:19697597](https://zenodo.org/records/19697597)，通过已有 [oral-scrna-atlas](https://github.com/stevenhuangfannk-creator/oral-scrna-atlas) 接口引用。所有输入来自PI观察数据，没有实际WT/KO组。canonical H5AD `layers/counts`导出2,996个broad fibroblast、21,934个跨研究交集基因。

Atlas `celltype_fine` 为broad注释复制，作者逐细胞subtype/cluster未取得。模型120细胞均provisional；正式fine state未独立确认。原参考UMAP不能变成反事实轨迹。

冻结规则用全21,934基因分母的log1p(CP10k)：炎症五基因均值达到供者内75百分位，炎症和Matrix各至少2基因检出，免疫/上皮/内皮模块各少于2基因检出。得到551个Inflammatory_enriched细胞。满足最少15状态细胞的三供者，各以种子271828无放回取40，共120。一个供者有两个文库，仍仅算一名供者。精确供者/文库ID映射在本地审计中，GitHub不提供逐供者资料。

| 程序 | 基因 | 用途 |
|---|---|---|
| Inflammatory | CXCL6, CXCL8, CSF3, IL6, CCL2 | 操作性选择 |
| Matrix | COL1A1, COL1A2, DCN, LUM, COL3A1 | 基质支持 |
| Myofibroblast | ACTA2, TAGLN, MYL9, TPM2 | 描述，非亚群命名 |
| Stress | FOS, JUN, HSPA1A, HSPA1B, DDIT3 | 应激审查 |

120细胞无上述跨谱系旗标，但不证明绝对纯度。Marker与选择共享表达，不能作为独立身份证据。供者内相对高分不证明供者间绝对炎症强度相同；未选入供者与文库不均限制代表性。

## TF选择与460基因

旧TF审查复用 [TF Atlas](https://github.com/stevenhuangfannk-creator/tf-regulatory-network-atlas) 的CollecTRI/PROGENy和ULM/VIPER。JUND主候选、STAT4机制参考来自旧冻结规则；STAT4不是阴性对照或已证明驱动因子。两方法共享表达与先验，不是独立生物验证。Remaining_fibroblast集合存在跨谱系旗标，不是已认证稳态对照，TF差异可能混有纯度、应激或技术因素；本次未事后清洗/换候选。

面板先要求三供者各至少一次检出，再按120细胞raw-count variance取450，加入共同检出的固定程序、六审查TF和两目标，最终460；29个protected中10个在原450之外。规则不使用真实KO，但显式保护靶点；raw variance受深度/供者影响，共同检出会丢失稀疏或供者特异调控因子。

炎症、基质、肌成纤维、应激模块覆盖5/5、5/5、4/4、5/5；周期仅PCNA（1/4）。缺失不是不响应。引擎在面板过滤后归一化，分母不同于状态定义，回放不得静默换尺度。

## 实际算法与限制

直接调用外部官方DoseDirKO数值核心，无agent、LLM或API。460基因触发官方g>400分支，**跳过CP，只平均PCR关联网络**；eligible不等于CP成功。网络接近对称，目标行约定不证明因果方向。observer仅保存原函数网络并原样返回，数学不变。

effect为无向网络嵌入距离，delta为signed propagation，都不是实测log2FC。KD alpha=0.5是网络参数，不是测得RNA/蛋白敲低率。

## 失败不能省略

JUND pooled CXCL8、IL6为负delta，却分别与供者多数、全部方向冲突；CSF3、CCL2也各有反向供者。CXCL6同号但没有真KO证据。STAT4有ambiguous输出，不能强行二元化。图库保留聚合冲突，不提供供者ID。

JUND seed Spearman中位数：delta约0.943、effect约0.375；STAT4约0.939、0.253。delta与direct-only近同（约0.999），不能当准确率优势。旧三供者多数≥60%门槛区分度不足，不作为泛化证据。

已完成两次工具回放，每次8调用、12算法运行、44数值文件一致。本次只重新哈希已有结果，没有重做旧完整13调用/25运行。INPUT_OK=PASS（限探索subset）、RUN_OK=PASS、PREDICTION_STABLE=FAIL、BIO_VALIDATED=NOT_EVALUATED，整体PARTIAL。

可表述受限关联网络的候选预测与部分方向不一致。不能宣称亚群特异机制、JUND抗炎、分泌降低、免疫功能改善、准确真实KO或治疗价值。旧科研项目和上游仓库保持不变；完整保存核查在本机日志。
