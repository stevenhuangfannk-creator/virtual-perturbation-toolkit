# 发布范围 / Release scope

`v0.1.0-exploratory` 是工具版本，科学判定仍为 PARTIAL。GitHub 为主要维护版本；本地 checkout 的修改经测试、提交和推送后才成为维护版本。安装的 Skill 只保存说明、launcher 与仓库路径，不复制数值核心。

仓库包含自有适配器、输入检查、资源边界、评估、绘图、测试、配置模板、来源与科学边界说明、脱敏的真实历史摘要图库。没有官方 DoseDirKO 核心、源代码包、权重、原始矩阵、逐细胞或逐供者数据、运行环境、凭据、本机运行路径。

原始 JUND 配置保留为忽略文件 `examples/jund_history.local.json`，旧运行输出和日志仍在本地 `outputs/`、`logs/`。发布配置 `examples/jund_history.json` 仅是迁移路径模板，保留历史算法参数；不能下载仓库后直接重建没有再分发的原始输入。44项哈希验收证明既有产物与历史相符，不是新的科研分析或独立生物学验证。

输入、文库和供者ID在真实本地运行中必须保留用于审查；排除Git不意味着删除。每次输出记录输入哈希、基因/细胞顺序、物种、状态来源、引擎哈希和参数。完整输出保存到未跟踪目录。新任务不继承旧病例的INPUT/RUN状态。

图库只有有限pooled预测、网络摘要与自有聚合审计统计。数据源 [Zenodo:19697597](https://zenodo.org/records/19697597) 的公开API标为CC-BY-4.0、creator Lin, Weimin；归因及元数据日期异常见许可审查。图库不包含新的实验，也不提供供者级重识别映射。

首版暂不额外授予统一开源许可证。自有代码按仓库权限管理；外部库、数据和官方核心分别遵守原许可。Private既不解决第三方授权，也不替代数据审查。
