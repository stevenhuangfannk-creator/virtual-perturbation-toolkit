# 图库来源与边界 / Gallery provenance and boundaries

本轮发布四类历史 JUND / STAT4 摘要图，各含 PNG、PDF、SVG。源数据来自已有数值回放，不重新筛选、重建网络、调整参数或开展生物学验证。转换代码和绘图代码为工具自有实现；没有复制第三方作者图片、核心算法或模型资产。

## 科学解释边界 / Interpretation boundaries

`Observed` 只用于既有输入与来源审查事实。本例的“炎症”标签是多基因程序富集操作定义，不能写为正式炎症性成纤维细胞亚群的特异预测。`WT` 是官方算法的干扰前网络标签，不是实际 WT 实验样本。

所有网络边、effect 与 delta 均为 `Model-predicted`。alpha=0.5 是网络行缩放；网络关联权重不是因果效应；effect 不是表达变化方向；delta 不是真实 log2FC。算法分位范围、三次重复的最小–最大及符号频率，不是独立供者的生物学置信区间或正确概率。图中不添加不适用的 DEG、FDR、AUROC 或 AUPRC。

没有匹配真实 KO/KD，因此没有 `Experimentally validated` 面板。历史回放为 44 项文件哈希一致，是软件复现证据；它与真实预测正确性是不同问题。JUND pooled CXCL8 / IL6 为负，而供者存在 2/3、3/3 的符号冲突；这些结果原样呈现，不能写为可靠抗炎或治疗靶点结论。delta 与 direct-only 约 0.999 相关，未提供比简单基线更准确的证据。

四层原状态：INPUT_OK=PASS（仅探索性输入）、RUN_OK=PASS、PREDICTION_STABLE=FAIL、BIO_VALIDATED=NOT_EVALUATED。科学结论仍为 PARTIAL。不同算法的数值尺度不得在统一柱状图上混为可比响应。

## 图件契约和审查 / Figure contract and QA

核心结论：**工具可精确回放并形成可追溯图件，但历史示范的生物学方向与稳定性仍不足。** A 审查输入定义，B 展示关联量，C 展示固定程序预测，D 保留稳定性失败和缺失验证。布局为定量网格及输入文字卡片；全程 R 绘图，沿用原项目 R 体系。

PNG 300 dpi，宽 210 mm；PDF/SVG 保留文字；最小正文 7 pt。没有为了审美随机抽样，不隐藏缺失基因。B 为固定 top12 展示摘要，C 固定程序全部保留，D 三次算法重复全部保留。发布 CSV 保留原输出精度；热图显示两位有效数字，避免把小分数舍入为零而掩盖方向。

详见 [Gallery README](../gallery/README.md)、[数据与参数](../gallery/data/historical_summary.json)、[来源 SHA256](../gallery/source_manifest.json)、[绘图环境与 MD5](../gallery/figure_manifest.json)、[绘图代码](../gallery/plot_gallery.R)。这些索引可追踪来源，但不意味着用户在未持有原始本地数据时也能重新运行数值算法。仅从已发布摘要重绘图库可以独立完成。

交付 QA：[图库检查记录](图库验收记录.md)。Cairo 的 raw `Tf` 字号检查不适用于实际缩放字体，原报告保留该失败标记；实际变换后的 PDF 文本检查最小 7.0 pt，四图逐面板视觉检查通过。文件/绘图 QA 通过不改变 PREDICTION_STABLE 或 BIO_VALIDATED。


C 图复审修正：原摘要表的 `direction=ambiguous` 此前未在热图明确标记，现以 `?` 保留 STAT4 CXCL6、CXCL8、ACTA2、TPM2 的方向未确定状态，并更新图例及中文图注。该标记不修改均值或预测方向；不能把非零 delta 解释为可靠定向响应。本次仅重绘已有摘要，没有重跑数值引擎或改变分析参数。
