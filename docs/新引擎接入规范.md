# 新引擎接入 / Engine integration

首版只有 `dosedirko` 外部核心适配器。CellOracle、scTenifoldKnk 仅登记历史/候选状态 `NOT_INTEGRATED`，调用会失败而非产生替代预测。

新增引擎先核查源代码、权重、数据许可证和资源，再独立实现适配器。不能复制未知许可代码，不能把一种方法的分数改名为另一种的表达响应。登记输入要求、输出数学意义、可用平台、锁定版本、参数、依赖、失败条件及独立验证范围。

接入验收需要合法的小型软件夹具、运行清单、可重现的数值检查与有意义的失败测试。稳定性与真实实验验证分别记录；软件通过不自动将候选引擎标记为 `BIO_VALIDATED`。实际干扰数据若不可获得，明确未验证，不借用其他组织的文献冒充本任务验证。

图件从实际输出生成，使用 Observed、Model-predicted、Experimentally validated 标签。展示规则先固定，保留缺失、ambiguous、供者异质性和失败。与真实结果及简单基线的评价必须同口径，并明确域外泛化范围。安装大组件、下载大资产或新增远程项目不属于自动接入步骤。
