# 方法与证据层级 / Method and evidence levels

Virtual Perturbation Toolkit 将已处理、已说明来源的单细胞 counts 和指定目标基因交给选定数值引擎，输出可检查的模型结果。它默认复用原课题的细胞注释，不重建完整单细胞分析，不自动发现或命名亚群，不调用外部 LLM 解释结果。

## 1. “虚拟敲除”实际是什么

第一阶段可调用引擎是历史实际运行过的 DoseDirKO。它从未受真实 KO 的输入细胞估计 PCR 关联网络，将目标基因的出边按 `1-alpha` 缩减，再计算网络嵌入变化和有符号传播。`alpha=1` 是模型的完整出边干预，`0<alpha<1` 是部分出边干预。该参数不是实验检测到的 mRNA 敲低率，也不等于某剂量 siRNA、CRISPR 编辑效率或抑制剂浓度。

计算没有重新生成观测 cells×genes 的真实表达 counts，不能把输出称为实验后的转录组或真实细胞状态迁移。关联网络可能受细胞混合、深度、应激、选择规则和基因覆盖影响；算法的行边方向并非已经识别的因果方向。

| DoseDirKO 数值 | 含义 | 不应解释为 |
|---|---|---|
| `effect_mean` | WT/模拟干预网络的对齐嵌入距离均值 | log2FC、表达倍数、概率、DE 显著性 |
| `effect_ci_low/high` | 算法重复 effect 的 2.5%/97.5% 分位数 | 生物学重复置信区间 |
| `delta_mean` | signed network propagation 的平均值 | 真实 KO log2FC、准确表达预测、可跨引擎比较的同一尺度 |
| `direction` | 重复中符号频率达到官方阈值时为 up/down，否则 ambiguous | 已验证表达方向 |
| `p_up/p_down` | 算法重复中正/负符号的比例 | 正确方向的统计概率或 P 值 |
| `topk_freq` | 官方默认 Top-50 effect 在算法重复中入榜的频率 | 本工具图中 Top-K、因果可信度或生物学重复性 |

实际执行分支要随运行记录：官方 `g>400` 时平均 PCR 网络，跳过 CP；符合 CP 条件也不保证该分支最终成功。不得仅根据论文方法图声称每次运行都完成全部算法步骤。

## 2. 图件的三类标签

- **Observed / 实际观察**：输入细胞的原始 counts、覆盖、已提供状态、样本来源，以及数据内表达总结。表达规则选出的高分状态仍是观察性集合，其 marker 图不能作为独立验证。
- **Model-predicted / 模型预测**：WT 关联网络、虚拟干预网络、effect、delta、模型供者比较和算法稳定性。软件推断边不标为已证实分子关系。
- **Experimentally validated / 实验验证**：适用的独立真实干预数据实际支持的效应。没有匹配实验时不用此标签；文献中其他背景的干预只可列为外部参考。

“实际运行了模型”属于真实计算事实，不等于模型生成的生物学变化已经真实发生。图面同时保留 ambiguous、缺失和方向冲突；分布相近或排名稳定不能代替真实干预指标。

## 3. 四层验收状态

四层分别记录，使用机器可读名称；每层包含 `state`（`PASS`、`FAIL`、`NOT_EVALUATED`、`NOT_APPLICABLE`）和 `reason`，状态不自动向后传递。具体实现输出在 `results/status.json`。输入警告另行保留，不将警告忽略后填成生物学 PASS。

| 层 | 要回答的问题 | 能通过的证据 | 通过也不能说明 |
|---|---|---|---|
| `INPUT_OK` | 输入、来源、ID、细胞身份范围及 raw counts 是否满足此次调用要求？ | counts 有限/非负/整数；ID唯一且顺序对应；物种/基因标识明确；已完成的 QC 与状态来源可追溯；目标有覆盖；受限范围正确记录 | 精细亚群最终正确、纯度完美、独立生物学 n 足够 |
| `RUN_OK` | 引擎是否实际完成并可回放？ | 有版本/参数/输入哈希；输出有限；目标参与网络；重复核对在声明容差内一致；错误与分支完整记录 | 模型预测准确、有因果意义或治疗价值 |
| `PREDICTION_STABLE` | 在预设测试中哪些数值足够一致？ | 先冻结指标/阈值；分别审查 effect/delta、种子/供者；保留冲突与不确定性 | 真值正确；多个算法种子是生物学重复；稳定关联是因果关系 |
| `BIO_VALIDATED` | 有独立、适用的真实实验支持预测吗？ | 背景/干预/细胞类型匹配的真实 KO/KD；供者独立与无泄漏；同口径基线和预设指标；完整报告失败 | 其他物种/状态/刺激下通用、临床疗效 |

如果 raw counts 缺失、状态来源不可追溯、把疾病观察组冒充 KO 或声称的亚群无法确认，应阻止相应不当分析/声明。若 broad 身份和来源支持有限探索，但 fine 状态是操作性标签，可记录受限输入准入及明确警告，不发明新亚群。纯度旗标不是确定污染诊断。

稳定性应限定到具体输出。不能仅因 delta 排名较稳定而将不稳定 effect、供者方向冲突和无真值都省略。供者至少两个文库时按供者汇总，不能把文库或细胞当独立生物学重复。没有合适真实 KO 时 `BIO_VALIDATED=NOT_EVALUATED`，不得计算未定义的 AUROC/AP，更不能标为 PASS。

本次模块化回放前固定的报告门槛是：delta 与 effect 的种子排名相关均达到 0.8，且固定程序的 pooled/供者方向无冲突。该门槛是在已看过历史结果后为封装报告定义，属于 historical-informed 的透明审查约定，不是新的独立科学验证；没有改变旧算法参数。历史案例预期不能通过该总体稳定性门槛，不能降低阈值来制造 PASS。

## 4. 基线与真实验证如何使用

No-change、目标表达量、网络绝对出度和 direct-only signed input 可检查模型是否只是表达/网络结构的重新排序。有真值时，可在相同训练输入和测试数据上比较适用的误差、排名或恢复指标；没有真值时只能称结构比较，不能说优于基线。

DoseDirKO effect 只适合比较响应重要性排序；delta 提供候选符号但不是表达尺度。scTenifoldKnk 的 DR 调控距离没有表达方向；CellOracle 的状态向量不能直接当 log2FC。预留接口不意味着模型已安装、运行或通过本任务验证：引擎可用性以 registry 和 preflight 实际检查为准，不应给未验证引擎生产可用标记。

## 5. 历史 JUND 示例的正确用途

旧输入为三供者、120 个操作性炎症程序富集细胞、共同 460 基因面板。它是文件格式、官方引擎调用、历史数值核对及保留失败的实例，不是成功验证案例。新模块的 `outputs/jund_history` 实际经 Skill wrapper 完成 8 次官方调用、12 次算法运行，44 项 official CSV/网络 NPY/checkpoint NPY SHA 与原项目精确一致；本次没有重跑旧完整 13 次调用、25 次算法运行。

旧 JUND pooled 中 CXCL8/IL6 为负 delta，却分别与供者多数/全部方向冲突；effect 种子排序不如 delta 稳定；direct-only 排名几乎相同。没有匹配真实 PI JUND/STAT4 KO。旧规则的三供者 ≥60% 多数门槛过弱，不继承为可证明泛化的标准。新回放记录 INPUT_OK=PASS（限定探索性 subset）、RUN_OK=PASS、PREDICTION_STABLE=FAIL、BIO_VALIDATED=NOT_EVALUATED，旧总体判定继续为 **PARTIAL**。

可以在论文中写清模型、来源、参数、覆盖、探索性候选与限制。不能仅凭本结果声称 JUND 敲低抗炎、CXCL8/IL6 分泌降低、中性粒细胞功能改善，或已经获得特异性分子调控机制；上述因果关系需要匹配真实 siRNA/CRISPR、分泌、毒性和功能实验。历史案例不为通用 Skill 新增科研假设。

## 发布状态兼容

`NOT_EVALUATED` 是既有机器状态，含义为尚未评价（UNVALIDATED）；为保持旧数值和接口兼容，首版不改枚举。历史回放通过与科学稳定性失败同时成立。GitHub图库是无供者ID的有限摘要，完整结果保留本地。
