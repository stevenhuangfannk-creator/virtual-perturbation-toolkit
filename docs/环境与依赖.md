# 环境与依赖 / Environment and dependencies

首版实际验证平台是 Windows x64；launcher 使用 PowerShell，不宣称已经完成 Linux/macOS 端到端验收。launcher 和 Skill 同步仅需 Python 标准库。数值、监控与绘图运行时由任务配置独立指定，避免改动其他项目依赖。

实际版本：数值 Python 3.12.14，NumPy 2.4.6、pandas 3.0.6、SciPy 1.15.3、TensorLy 0.9.0、scikit-learn 1.9.1；H5AD读取使用anndata 0.13.4、h5py 3.16.0。监控 Python 3.11.9、psutil 6.0.0。R 4.6.1，ggplot2 4.0.3、patchwork 1.3.2、ragg 1.5.2、jsonlite 2.0.0、svglite 2.2.2。这些是工作站测试版本，不保证所有组合都兼容。

用 `python scripts/skill_sync.py doctor --config <job.json>` 查询依赖与外部源码哈希。缺依赖即BLOCKED；版本不一致提示重新运行软件验收。doctor不证明输入合格或生物学有效，也不自动安装依赖。

外部DoseDirKO来源与SHA必须先核实，不能把未经审查的新版本直接改哈希后冒充已验证。官方核心不包含在仓库；新机器需要自己合法取得组件，并填写 `engine.source_dir` 和实际运行时路径。10x用途不强制anndata/h5py；H5AD需明确counts layer。RDS还需已有SeuratObject/Matrix，适配器未实际RDS验证。

历史资源预算：2线程，工作集850MiB/private1000MiB、最低空闲192MiB、每阶段300秒，另有counts和网络估计预算。建议开始至少0.75GiB空闲RAM；不满足时保留诊断停止。阈值不是系统总RAM需求保证，后台波动和稀疏/稠密转换仍可能触发停止。

只需检查新launcher和已有外部核心时可执行明确合成的软件夹具（非科研结果）：

```powershell
python scripts/run_software_example.py --source-config <local_runtime_job.json> --work-dir logs/new_software_example
```

该脚本仅读取已有环境/引擎配置，生成48×24合成整数矩阵并有限调用；不重新运行JUND。新目录必须不存在，失败与成功均保留。运行此夹具不能提供真实干扰准确性证据。

仓库 `.gitattributes` 保留文件原字节，防止跨机器换行转换破坏SHA/MD5清单。修改图库数据或代码后应重新导出、绘图并更新清单，不能手改哈希制造通过。
